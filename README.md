# Keerthi Reddy — Portfolio

Single-file static site (index.html). Everything is bundled inside; fonts load from Google Fonts.

## Host on GitHub Pages
1. Create a repo (e.g. `Keer0423.github.io` for https://keer0423.github.io/, or reuse `portfolio`).
2. Upload index.html and .nojekyll to the repo root, commit to main.
3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
4. Live in about a minute.
